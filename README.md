# Birthday site (Next.js)
1. `npm install` then `npm run dev` → http://localhost:3000
2. Edit all text in `lib/content.js` (placeholders are in [BRACKETS]).
3. Put files in `public/assets/`: voice1.mp3, voice2.mp3, voice3.mp3, photo1.jpg, photo2.jpg
4. Push to GitHub, import the repo on Vercel, deploy (no settings needed).
